# Reading Elite — Product Vision & Learning Design
A product design and systems-architecture project for an adaptive literacy platform. This repo contains the requirements, instructional design, and phased build plan I developed for an AI-supported reading coach aimed at K-12 students, parents, and teachers. 
**Status:** Design/planning artifact (academic project) — not a built application. This repo documents the requirements analysis, system design, and product roadmap work. 
## What's inside
- `Reading_Elite_Full_Vision_and_Learning_Plan.pdf` — full product vision document covering:
-  Core feature set (speech-to-text reading assessment, skill diagnosis, adaptive lesson recommendation, progress reporting) 
- Literacy skill taxonomy (phonics, morphology, fluency, vocabulary, comprehension, writing/grammar, test-taking strategy)
- The personalized learning engine's feedback loop (Listen → Analyze → Diagnose → Teach → Practice → Recheck → Adapt)
- Dashboard requirements for three distinct user roles (student, parent, teacher/tutor)
- A 5-phase build roadmap, from a working core (accounts, recording, basic scoring) through advanced adaptive intelligence
- Accessibility, privacy, and responsible-AI design principles (bias testing before high-stakes scoring, human oversight of AI recommendations, age-appropriate data retention)
## Why this project 
This was built as a requirements-engineering and systems-design exercise: taking an ambiguous, high-value problem (personalized reading instruction) and turning it into a structured, phased, technically groundable product plan — including the AWS-based application architecture and PostgreSQL data model considerations needed to support it. 
## Skills demonstrated 
- Requirements gathering and stakeholder analysis (three distinct user types with different needs)
- Feature scoping and phased delivery planning (MVP → full platform)
- System architecture thinking (cloud application design, database considerations, feedback-loop system design)
- Responsible AI / accessibility considerations built into the design from the start, not bolted on after
